# 03 · UI 框架

## 1. 响应式核心（`src/scene/signal`）

粒度决定一切。Flutter 的 `setState` 从最近的 StatefulWidget 重建整棵子树，再走一遍全量 diff；我们做**信号级更新**：只有真正依赖某个值的元素属性会被重写，签名不变则整条链路（style → layout → paint）都不触发。

```cpp
namespace nq {

template <class T> class Signal {          // 分代 arena（id + generation），无 shared_ptr
 public:
  T  get() const;                          // 读取时向当前 Observer 登记依赖
  void set(T v);                           // 标记依赖者 dirty，入 batch 队列
  void update(nq::FunctionRef<void(T&)>);  // 原地更新，避免临时对象
  Connection subscribe(nq::FunctionRef<void(const T&)>);
 private:
  SignalId id_;
};

template <class T> class Computed;         // 惰性 + 记忆化，依赖变化才失效
class Scope;                              // 生命周期作用域，析构时自动断开所有 Connection
class Batch;                              // RAII：作用域结束统一 flush，一帧最多一次

} // namespace nq
```

- **Observer 栈 + 分代 id**：读取时把 `SignalId` 记到当前 Observer 的依赖表（arena 上的 intrusive 链表），零虚函数、零哈希。
- **事务**：`Batch` 把一帧内所有 `set` 合并，flush 时拓扑排序传播，相同元素只重算一次。
- **Computed 的拓扑序**：用"深度 + 单调序号"保证菱形依赖只算一次，不做动态拓扑重排（够快且可预测）。
- **逃生舱**：`Signal::peek()` 不登记依赖（事件回调里常用）。

## 2. Element 树与协调

```cpp
enum class Kind : uint8_t { kRoot, kBox, kText, kImage, kPath, kScroll, kLayer,
                            kPlatformView, kFragment, kCustom };

struct Element {              // arena 分配，稳定地址（不搬移）
  Kind kind; uint32_t key;    // key 非 0 时参与列表 diff
  StyleHandle style;          // 计算后样式的句柄（SoA 存储）
  LayoutNode* layout;         // 布局节点（与 element 1:1，分离以便并行）
  dl::DrawList* dl;           // 本级显示列表（可为空，表示透明容器）
  Element* first_child, *next_sibling, *parent;
  uint8_t dirty;             // kDirtyStyle|kDirtyLayout|kDirtyPaint|kDirtyCompositing
};
```

- **不做 VDOM diff**：属性更新由 signal 直写 `Element` 字段（`signal.bind(&Text::text)`），结构变化才走协调器。
- **结构协调只在 `for_each` / 条件分支处发生**，用 key 做最长递增子序列（O(n log n)），支持移动而非重建。
- **生命周期**：`mount / update / unmount`；unmount 时元素进回收池（同 kind 复用），避免逐帧分配。
- 元素地址稳定（arena + 不搬移），所以布局/绘制可以安全持有裸指针；树重建时整块 arena 一起释放。

## 3. C++ DSL

三个层次，按场景选，**共同产出同一棵 `Element` 树**：

```cpp
// (a) 聚合初始化 —— 最"像数据"，最快，无宏
Column{.gap = 8, .padding = 16, .children = {
  Text{.text = u8"计数器", .style = t.title},
  Row{.gap = 8, .children = {
    Button{.on_click = [&]{ count.update([](int& c){ ++c; }); }, .label = u8"+1"},
    Button{.enabled = count.map([](int c){ return c > 0; }), .label = u8"-1"},
  }},
}};
// (b) builder 链 —— 需要条件/循环/局部变量时
auto card = Box{.radius = 12}.append(Text{.text = title}); if (hot) card.border(1, kAccent);
// (c) UI IR（运行时）—— 其他语言绑定、热重载、服务端下发
Element e = ir::parse(json_or_binary);   // 与 (a)(b) 完全等价
```

不上预处理器宏 DSL：C++ 宏的错误信息是灾难，且与 IDE/调试器冲突。`ir::` 的等价性保证了"语言中立"不是口号。

## 4. 布局（`src/layout`）

```cpp
using LayoutUnit = int32_t;         // 1/64 px，饱和运算
struct Constraints { LayoutUnit min_w, max_w, min_h, max_h; };  // 约束下行
struct Fragment   { LayoutUnit x, y, w, h; };                   // 尺寸上行（含基线）
```

| 容器 | 说明 |
|------|------|
| `Row / Column` | flex 主轴/交叉轴，`gap`、`justify`、`align`、`grow`、`basis`、`wrap` |
| `Grid` | 显式轨道模板 + 自动放置（子集：不做 subgrid/负索引） |
| `Stack` | 绝对定位，`insets` + `align` |
| `Scroll` | 视口，内容尺寸独立测量 |
| `InlineText` | 行内文本流：断行、双向、基线、行高、首行缩进、`vertical_align` |

增量机制（相对 Flutter 的核心优势）：

1. **脏标记四态**：`style / layout / paint / compositing` 独立传播，style 变化不一定触发布局（例如只改颜色）。
2. **布局根**：向上找到"尺寸不受影响"的最近祖先作为布局根，只重算该子树。
3. **Fragment 缓存**：节点缓存 `(样式版本, 入参约束, 子节点尺寸版本)` 的哈希；三者未变则直接复用上一帧 fragment，**O(1) 跳过**。
4. **测量缓存**：flex/grid 的 intrinsics 两趟测量按 `(内容, 约束轴)` 缓存，避免 O(n²)；文本用"与宽度无关的断行机会表"（见 04），改变宽度只需重新贪心分配，不重新整形。
5. 布局过程**无分配**（全部写进预分配的 fragment 数组）；超过阈值时按"布局根"切分到光栅池并行（第二阶段）。

## 5. 样式（`src/style`）

- `ComputedStyle` 用 **SoA**（结构数组）存储：热字段（间距/尺寸/颜色/不透明度/变换）放在紧凑数组里，冷字段（字体族列表、滤镜链）走句柄 → 缓存友好。
- **只有文本属性继承**（font/color/line-height/letter-spacing），其余全部显式 —— 比 CSS 的隐式继承可预测得多。
- 状态机式伪状态：`hover / active / focus / focus_visible / disabled / selected / invalid`，状态变化只重算受影响元素的样式（不重跑选择器）。
- 主题 = 一组命名 token（`color.surface`, `radius.md`, `text.title`），支持多套主题热切换（token 也是 Signal）。
- 可选 CSS 子集解析器（`style/css`）：把 `.card:hover { border-radius: 8 }` 编译到同一套 `ComputedStyle`，给设计师用。**只解析，不实现 Web 层叠优先级之外的复杂规则**。

## 6. 动画（`src/scene/anim`）

| 类型 | 驱动 | 例子 |
|------|------|------|
| 隐式过渡 | UI 线程 | 样式变化自动补间（`animate = { .dur = 150ms, .curve = kEaseOut }`） |
| 显式曲线/弹簧/衰减 | 视情况 | `Anim::spring(stiffness, damping)`、手势松手速度衰减 |
| **合成线程动画** | 合成线程 | transform / opacity / clip / filter 参数 / 滚动惯性 |

判定规则：动画只影响合成属性且元素已独立成层 → 自动下沉合成线程（UI 线程完全不参与）；否则在 UI 线程 tick，并在 devtools 标注"会掉帧的动画"。这是"UI 卡 50 ms 动画仍平滑"的来源。

## 7. 滚动

- 惯性/回弹物理 `fling` + 嵌套滚动（内层消费不完传给外层）。
- 滚动位置是**合成线程状态**，UI 线程按需（阈值/惯性结束时）被通知，避免每帧跨线程同步。
- 滚动锚定（内容插入时视觉不跳）、吸顶/吸底、加载更多预取、滚动条自绘。
- 无障碍滚动动作直接改合成线程状态并通知语义树。

## 8. 输入

- 命中测试在 **fragment 树**上做（不是元素树）：已排除 `clip`/`transform`，O(log n) 用分桶网格。
- 事件路由：捕获 → 目标 → 冒泡；焦点环（`Tab` 顺序显式指定 + 几何推断兜底）；快捷键先给原生菜单（保证与系统习惯一致）。
- 高频鼠标（1000 Hz）在合成线程**按帧合并**，只保留位置轨迹（用于手势/画笔），避免事件风暴。
- 手势识别器：tap/长按/双击/拖拽/双指缩放/旋转，统一 `Pointer` 状态机，支持"未决时吞事件"的正确语义。
- DnD：与平台原生 DnD 互通（拖出到 Finder/Explorer，拖入文件）。

## 9. 无障碍（`src/a11y`）

- 语义树从 Element 派生（`role / label / value / states / actions / bounds / focusable`），**增量 diff** 后同步给平台 API（AT-SPI2 / UIA / NSAccessibility / Android / iOS）。
- 自定义绘制内容通过 `SemanticsNode` 显式声明（虚拟子树），支持屏幕阅读器逐项导航。
- 焦点顺序、可访问名称的**多来源合并**（内联文本 + `label_for` + 显式 aria-like 属性）。
- 文本字段暴露 `TextPattern`（选区、光标、单词边界）与 `EditableText`，支持屏幕阅读器读写与 IME 联动。
- CI 里跑无障碍"审计"：未命名按钮、对比度不足、焦点陷阱、重复 id 一律报警。

## 10. 可观测性（`src/devtools`）

| 面板 | 内容 |
|------|------|
| 帧时间线 | build/style/layout/record/raster/composite/present 分段瀑布图，P99 高亮 |
| 布局检查 | 约束/尺寸/基线、布局根、缓存命中与失效原因 |
| 重绘热图 | 脏矩形、每元素重绘次数、像素级"是谁画的"（GPU 拾取或 CPU 标记） |
| Overdraw | 叠加次数伪彩 |
| 文本 | run/glyph/断行点/字距可视化，整形缓存命中率 |
| 内存 | arena、atlas、瓦片、图像池占用与驱逐曲线 |
| 无障碍 | 语义树 + 平台同步差异 |

实现方式：引擎内建结构化事件流（`nq::diag::Trace`，环形缓冲 + 可选的 Chrome Trace JSON 导出），devtools 是一个独立的本地 Web 页面（走 unix socket / 命名管道），不占 UI 线程。
